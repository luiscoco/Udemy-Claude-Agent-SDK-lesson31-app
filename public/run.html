Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Prerequisites

Use Node.js 24+, API credit and a supported model. Windows may require Git Bash. Python is needed only to regenerate the student pages.

node --version
npm --version
02

Install and create your .env file

From presentations enter the application, install locked dependencies, preserve an existing .env and enter your model key privately.

cd .\agent-sdk\lesson31-clarifying-questions
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the application

Keep the terminal open and visit port 3131. Navigate between the lab, learning goals, setup, UML architecture and code walkthrough.

npm start
# http://127.0.0.1:3131
04

Answer actual generated questions

Run Single select, choose an option and submit. Repeat with Multi-select and Question batch. Observe how the full question texts map to actual selected labels. An explicitly scripted CLI demonstration requires the flag below.

npm run sample:env -- single --answer-first
npm run sample:env -- multi --answer-first
npm run sample:env -- batch --answer-first
05

Try your own words and previews

In Other select the host-provided custom-answer control and type your own words. HTML and Markdown experiments display optional previews actually generated by Claude. The general-reply section sends response instead of per-question answers.

npm run sample:env -- free-text --answer-first
npm run sample:env -- html --answer-first
npm run sample:env -- markdown --answer-first
06

Compare plan mode, allow entries and cancellation

Answer the plan-mode question before reading the plan. Confirm the allow-entry case still needs a human answer. In Cancel, cancel while the callback waits and inspect the empty answer map and pending count.

npm run sample:env -- plan --answer-first
npm run sample:env -- preallowed --answer-first
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3131
# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. Answer within two minutes or cancel. Missing option previews are not replaced by invented mockups. Other text belongs in a question answer; a general response is a separate reply. If a model does not ask as requested, inspect the actual SDK events before retrying.
